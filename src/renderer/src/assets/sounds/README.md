# Bildirim sesleri

Buraya dört dosya koyarsanız uygulamayla birlikte paketlenir ve üretilen yedek seslerin yerine kullanılır:

- `buy.mp3`      alım (ör. Desert Eagle tetik/horoz sesi)
- `sell.mp3`     satış (ör. Desert Eagle atış sesi)
- `x.mp3`        X gönderisi (kuş cıvıltısı)
- `telegram.mp3` Telegram mesajı

`.wav` / `.ogg` de olur. Her dosya en çok 6 saniye ve ~1,5 MB olmalı. Dosya yoksa üretilen ses çalar.
Cihaza özel değişiklik için dosya koymanız gerekmez: Ayarlar → Bildirimler → "Ses yükle".
